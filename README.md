## 글 쓰기

`posts/` 아래에 마크다운 파일을 추가하면 목록에 나타납니다.
등록 절차는 없습니다.

```markdown
---
title: 제목
date: 2026-09-15
summary: 한 줄 요약
tags: [mysql, 성능]
---

본문
```

`title`과 `date`가 없으면 빌드가 실패합니다.

글의 종류와 제목 규칙은 [WRITING.md](WRITING.md)에 있습니다.
