  • 콜백은 서명만 확인하고 큐에 넣어, 콜백이 몰려도 DB가 영향을 받지 않게 했습니다.

역할
설계 · 구축
기술 스택
Kinesis, Firehose, S3(Parquet), Athena, AWS DMS(CDC), Snowflake, dbt

[ 구조 ]

위는 행동 이벤트 수집 경로, 아래 초록은 운영 DB 변경분(CDC) 적재 경로입니다.

[ 상세 구현 사항 ]

  • Firehose 앞에 Kinesis(7일 보관)를 두어 유실을 막고 다른 소비자를 붙일 수 있게 했고, 수집 서버를 API 서버와 분리해 결제 트래픽과 자원을 나눠 쓰지 않게 했습니다.

  • Snowflake 안의 LLM 상품 분류가 실패하면 매시 적재까지 멈추던 구조를 별도 태스크로 격리했고, 분류 모델을 바꿔 1,000건당 크레딧을 약 28% 줄였습니다.
